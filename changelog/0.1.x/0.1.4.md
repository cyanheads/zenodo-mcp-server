# 0.1.4 — 2026-10-25

## Changed

- **Tool errors** escape Markdown in error messages and recovery hints in `content[]`; `structuredContent` retains the raw strings.
- **Startup configuration** rejects fractional `MCP_HTTP_PORT` values and names the variable in the startup error.
- **Hosted client examples** include Claude Code, Cline, Cursor, and Claude Desktop connection instructions.
- **Desktop bundles** exclude source, scripts, documentation, and editor tooling.
- **Development guidance and audit tooling** track the framework's updated API contracts and attribute advisories to the installed direct dependency version.
