# 0.2.0 — 2026-10-28

## Added

- Publish the zenodo-guide skill as an MCP resource for version selection, funding identity, and file-inspection workflows.
- **Agent Plugins manifests** add root `plugin.json` and `mcp.json` for plugin discovery and stdio startup.

## Changed

- **Guide delivery** includes the guide and query reference in npm, Docker, desktop bundles, and plugin installs; MCP clients can read `skill://zenodo-guide/SKILL.md` and references through `skill://{+path}`.
- **Desktop packaging** excludes root development files, dependency build-only files, and node-gyp intermediate output while retaining compiled native addons.
- **Development tooling** refreshes framework skills, packaging validation, and the bug-report environment table; README setup and query guidance are condensed.
- **Dependency release age** moves from 3 days to 1 day.

## Fixed

- **Desktop bundle startup** preserves the MCP SDK's runtime `dist/ext/skills` modules while removing dependency agent documentation, with regression coverage ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)).
