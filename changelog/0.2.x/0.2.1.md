# 0.2.1 — 2026-11-21

## Added

- **Deposit timestamps** appear as `created` and `updated` in record detail, search hits, and version listings. Search accepts inclusive UTC deposit-date ranges through `deposited_from` and `deposited_to`. ([#28](https://github.com/cyanheads/zenodo-mcp-server/issues/28))
- **Study dates and locations** appear in record detail when supplied, with date types, complete GeoJSON geometry, and continuations for longer lists. ([#29](https://github.com/cyanheads/zenodo-mcp-server/issues/29))
- **Research text previews** support more formats, including Fortran, Newick, FASTA, and GFF3, when Zenodo serves them as `application/octet-stream`. ([#30](https://github.com/cyanheads/zenodo-mcp-server/issues/30))
- **Related identifier search** finds deposits that link to a DOI or HTTP(S) URL. A DOI lookup miss suggests this filter with `all_versions: true`. ([#31](https://github.com/cyanheads/zenodo-mcp-server/issues/31))
- **Mid-word regex notices** flag how Zenodo parsed a successful search and show how to search for the intended DOIs. DOI-field matches can be partial. Use record lookup to verify exact identity. ([#22](https://github.com/cyanheads/zenodo-mcp-server/issues/22))

## Changed

- **Build and packaging** require Bun 1.4.4 or later. Desktop bundles preserve dependency runtime modules and exclude the Vitest cache. Framework tooling and skills are synchronized.

## Fixed

- **DOI resolution** requires an exact match before returning or caching a record. DOI comparison and related DOI variants fold ASCII letters and preserve non-ASCII suffix characters. ([#27](https://github.com/cyanheads/zenodo-mcp-server/issues/27), [#31](https://github.com/cyanheads/zenodo-mcp-server/issues/31))
- **ZIP listing errors** return `archive_unavailable` with the download URL when Zenodo refuses access to the listing for a public ZIP. ([#26](https://github.com/cyanheads/zenodo-mcp-server/issues/26))
