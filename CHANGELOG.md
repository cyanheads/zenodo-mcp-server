# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-09

Argument repairs from mcp-ts-core 0.13.9–0.13.14: an integer record id, a numeric string for a page size, or null for an optional field is now accepted instead of rejected; tool errors carry their request id; HTTP defaults to stateless in code; look-alike hosts are no longer called a Zenodo instance.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-24

First public release: six read-only tools for searching Zenodo, resolving deposits by DOI or URL, walking version series, and listing and reading files, including .zip members.
